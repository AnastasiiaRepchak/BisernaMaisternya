# BisernaMaisternya
# Бісерна майстерня

Вебсайт-каталог автентичних українських бісерних прикрас ручної роботи (ґерданів, силянок, криз) із можливістю підбору готових виробів та розрахунку індивідуального замовлення.

## Технологічний стек

* **HTML5** — семантична розмітка сторінки з підтримкою стандартів доступності (WAI-ARIA, WCAG 2.1).
* **Tailwind CSS (CDN)** — утилітарна стилізація, адаптивна сітка (Mobile First) та кастомна конфігурація дизайн-токенів.
* **Google Fonts** — шрифтова пара *Cormorant Garamond* (заголовки) та *Plus Jakarta Sans* (основний текст).

## Дизайн-система

Основні токени проєкту налаштовані безпосередньо в `tailwind.config`:

* **Кольори:**
  * Основний акцент (`primary`): `#CC0033` (Carmine Red)
  * Стан наведення (`primary-hover`): `#A30029`
  * Основний текст (`dark`): `#1A1A1E`
  * Вторинний текст (`muted`): `#5A5A65`
  * Світлий фон секцій (`bgMuted`): `#F9F9FB`
  * Межі та рамки (`borderCustom`): `#EAEAEF`
* **Типографіка:**
  * Заголовки (`font-heading`): `Cormorant Garamond`
  * Інтерфейс та текст (`font-body`): `Plus Jakarta Sans`
